# 需求文档

## 简介

二手电子产品交易系统是一个现代化的在线平台，允许用户发布、浏览和购买二手电子产品。系统采用前后端分离架构，具有现代化的UI设计和完整的功能模块，包括用户管理、商品管理、订单管理、聊天功能和管理员后台。

## 系统特色

- **现代化UI设计**: 采用glassmorphism设计风格，渐变背景，响应式布局
- **实时聊天功能**: 买家卖家可以实时沟通，提升交易体验
- **完整的管理后台**: 管理员可以全面管理用户、商品、订单和系统设置
- **安全可靠**: JWT认证，角色权限控制，数据验证和错误处理
- **用户友好**: 直观的操作界面，清晰的状态提示，流畅的交互体验

## 术语表

- **系统**: 二手电子产品交易系统
- **管理员**: 具有系统管理权限的用户，负责审核和管理平台内容
- **用户**: 注册并使用平台的普通用户，可以发布和购买商品
- **商品**: 用户发布的二手电子产品信息
- **订单**: 用户购买商品后生成的交易记录
- **实名认证**: 用户提交真实身份信息进行验证的过程
- **商品审核**: 管理员对用户发布的商品进行合规性检查
- **账号状态**: 用户账号的可用状态（启用/禁用）
- **商品状态**: 商品的当前状态（上架/下架/已售）

## 需求

### 需求 1

**用户故事:** 作为管理员，我想要查看和管理所有注册用户的信息，以便维护平台用户质量和安全

#### 验收标准

1. WHEN 管理员访问用户管理页面 THEN 系统应显示所有注册用户的列表，包括用户名、注册时间、认证状态和账号状态
2. WHEN 管理员搜索特定用户 THEN 系统应根据用户名或邮箱返回匹配的用户信息
3. WHEN 管理员选择禁用某个用户账号 THEN 系统应将该用户账号状态设置为禁用，并阻止该用户登录
4. WHEN 管理员选择启用已禁用的用户账号 THEN 系统应将该用户账号状态恢复为启用，并允许该用户正常登录
5. WHEN 管理员查看用户详细信息 THEN 系统应显示该用户的完整资料、发布商品数量和交易历史

### 需求 2

**用户故事:** 作为管理员，我想要审核和管理平台上的所有商品，以便确保商品信息合规且符合平台规范

#### 验收标准

1. WHEN 用户提交新商品发布请求 THEN 系统应将商品状态设置为待审核，并通知管理员
2. WHEN 管理员审核商品并批准 THEN 系统应将商品状态更新为上架，并在平台上展示该商品
3. WHEN 管理员审核商品并拒绝 THEN 系统应将商品状态设置为已拒绝，并通知用户拒绝原因
4. WHEN 管理员发现违规商品 THEN 系统应允许管理员下架该商品，并记录下架原因
5. WHEN 管理员管理商品分类 THEN 系统应允许管理员添加、编辑或删除商品分类（如手机、电脑、配件等）

### 需求 3

**用户故事:** 作为管理员，我想要查看和管理所有订单信息，以便处理交易纠纷和监控平台交易状况

#### 验收标准

1. WHEN 管理员访问订单管理页面 THEN 系统应显示所有订单列表，包括订单号、买家、卖家、商品信息、订单状态和创建时间
2. WHEN 管理员搜索特定订单 THEN 系统应根据订单号或用户信息返回匹配的订单
3. WHEN 管理员查看订单详情 THEN 系统应显示完整的订单信息，包括交易双方信息、商品详情和交易金额
4. WHEN 管理员处理订单纠纷 THEN 系统应允许管理员添加处理备注并更新订单状态

### 需求 4

**用户故事:** 作为用户，我想要注册账号并完善个人信息，以便在平台上进行交易

#### 验收标准

1. WHEN 用户提交注册信息（用户名、邮箱、密码） THEN 系统应验证信息格式，创建新账号并发送验证邮件
2. WHEN 用户登录系统 THEN 系统应验证用户名和密码，并在验证成功后允许用户访问平台功能
3. WHEN 用户提交实名认证信息 THEN 系统应保存认证信息并将认证状态设置为待审核
4. WHEN 用户修改个人信息 THEN 系统应验证新信息的有效性并更新用户资料
5. WHEN 用户修改密码 THEN 系统应要求用户输入原密码进行验证，并在验证通过后更新为新密码

### 需求 5

**用户故事:** 作为用户，我想要管理我的收货地址，以便在购买商品时选择合适的收货地址

#### 验收标准

1. WHEN 用户添加新收货地址 THEN 系统应验证地址信息的完整性（收货人、电话、详细地址），并保存该地址
2. WHEN 用户编辑已有收货地址 THEN 系统应更新该地址信息并保持其他地址不变
3. WHEN 用户删除收货地址 THEN 系统应移除该地址，并在该地址为默认地址时提示用户设置新的默认地址
4. WHEN 用户设置默认收货地址 THEN 系统应将选定地址标记为默认，并取消其他地址的默认标记
5. WHEN 用户查看收货地址列表 THEN 系统应显示所有已保存的地址，并突出显示默认地址

### 需求 6

**用户故事:** 作为用户，我想要发布和管理我的二手电子产品，以便出售闲置物品

#### 验收标准

1. WHEN 用户提交商品发布信息（标题、描述、价格、分类、图片） THEN 系统应验证信息完整性，创建商品记录并设置状态为待审核
2. WHEN 用户编辑未售出的商品 THEN 系统应更新商品信息并重新提交审核
3. WHEN 用户查看我的商品列表 THEN 系统应显示该用户发布的所有商品及其当前状态（待审核、上架、下架、已售）
4. WHEN 用户选择下架商品 THEN 系统应将商品状态更新为下架，并在平台上隐藏该商品
5. WHEN 用户选择重新上架已下架的商品 THEN 系统应将商品状态更新为待审核，并提交给管理员审核

### 需求 7

**用户故事:** 作为用户，我想要浏览和搜索二手电子产品，以便找到我需要的商品

#### 验收标准

1. WHEN 用户访问商品浏览页面 THEN 系统应显示所有已上架的商品列表，包括商品图片、标题、价格和发布时间
2. WHEN 用户按分类筛选商品 THEN 系统应只显示属于选定分类的商品
3. WHEN 用户搜索商品关键词 THEN 系统应返回标题或描述中包含该关键词的商品
4. WHEN 用户按价格排序商品 THEN 系统应按照价格升序或降序重新排列商品列表
5. WHEN 用户查看商品详情 THEN 系统应显示完整的商品信息，包括详细描述、多张图片、卖家信息和发布时间

### 需求 8

**用户故事:** 作为用户，我想要购买商品并创建订单，以便完成交易

#### 验收标准

1. WHEN 用户选择购买商品并提交订单 THEN 系统应创建订单记录，包含买家、卖家、商品信息和收货地址
2. WHEN 订单创建成功 THEN 系统应将商品状态更新为已售，并通知买家和卖家
3. WHEN 用户查看我的订单 THEN 系统应显示该用户作为买家或卖家的所有订单及其状态
4. WHEN 用户查看订单详情 THEN 系统应显示完整的订单信息，包括商品详情、交易金额、收货地址和订单状态
5. WHEN 买家确认收货 THEN 系统应更新订单状态为已完成

### 需求 9

**用户故事:** 作为系统，我需要验证所有用户输入数据，以便确保数据完整性和安全性

#### 验收标准

1. WHEN 用户提交包含空字段的必填表单 THEN 系统应拒绝提交并显示具体的错误提示
2. WHEN 用户输入格式不正确的邮箱地址 THEN 系统应拒绝该输入并提示正确的邮箱格式
3. WHEN 用户输入过短或过长的密码 THEN 系统应拒绝该密码并提示密码长度要求（8-20个字符）
4. WHEN 用户上传超过大小限制的图片 THEN 系统应拒绝上传并提示图片大小限制（单张不超过5MB）
5. WHEN 用户输入负数或零作为商品价格 THEN 系统应拒绝该价格并提示价格必须为正数

### 需求 10

**用户故事:** 作为系统，我需要处理各种错误情况，以便为用户提供清晰的反馈

#### 验收标准

1. WHEN 数据库连接失败 THEN 系统应记录错误日志并向用户显示友好的错误提示
2. WHEN 用户尝试访问不存在的商品 THEN 系统应返回404错误并提示商品不存在
3. WHEN 用户尝试执行未授权的操作 THEN 系统应返回403错误并提示权限不足
4. WHEN 用户会话过期 THEN 系统应重定向到登录页面并提示用户重新登录
5. WHEN 系统发生未预期的错误 THEN 系统应记录详细错误信息并向用户显示通用错误提示

### 需求 11

**用户故事:** 作为用户，我想要与其他用户实时聊天，以便更好地沟通商品交易细节

#### 验收标准

1. WHEN 用户点击商品详情页的"联系卖家"按钮 THEN 系统应创建或打开与卖家的聊天会话
2. WHEN 用户发送消息 THEN 系统应实时保存消息并通知对方用户
3. WHEN 用户查看聊天列表 THEN 系统应显示所有聊天会话，包括最后一条消息和未读消息数量
4. WHEN 用户打开聊天窗口 THEN 系统应显示完整的聊天历史记录
5. WHEN 用户收到新消息 THEN 系统应在导航栏显示未读消息提醒

### 需求 12

**用户故事:** 作为用户，我想要使用现代化的界面，以便获得更好的使用体验

#### 验收标准

1. WHEN 用户访问系统 THEN 界面应采用现代化设计风格，包括渐变背景和玻璃态效果
2. WHEN 用户在不同设备上访问 THEN 界面应自适应屏幕尺寸，保持良好的显示效果
3. WHEN 用户进行操作 THEN 界面应提供流畅的动画效果和视觉反馈
4. WHEN 用户浏览首页 THEN 应显示滚动横幅和快速导航功能
5. WHEN 用户使用系统 THEN 所有交互元素应具有一致的设计风格和行为
